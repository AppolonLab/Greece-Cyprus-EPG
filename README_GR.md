# EPG Ελλάδας & Κύπρου — αυτόματη ενημέρωση

Αυτό είναι ένα έτοιμο *πρότυπο εγκατάστασης*, όχι ήδη δημοσιευμένη υπηρεσία. Χρειάζεται ένα δικό σου GitHub repository και ενεργοποίηση GitHub Pages.

## Εγκατάσταση

1. Δημιούργησε ένα **νέο repository** στο GitHub και ανέβασε **όλο το περιεχόμενο** του φακέλου του ZIP, κρατώντας τον υποφάκελο `.github/workflows/`.
2. Στο repository πήγαινε **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Πήγαινε **Actions → Update TV Guide → Run workflow** για την πρώτη εκτέλεση.
4. Έπειτα άνοιξε τη διεύθυνση που θα εμφανιστεί στο **Settings → Pages**. Η ίδια διεύθυνση θα περιέχει κάθε νέα έκδοση.

Το GitHub Actions ελέγχει τις πηγές ανά 2 ώρες (UTC). Η πραγματική εκτέλεση των προγραμματισμένων workflows μπορεί να καθυστερεί. Αν τα αρχεία δεν κατέβουν, δεν είναι έγκυρα ή δεν έχουν πρόγραμμα για σήμερα/αύριο, η δημοσίευση **δεν** γίνεται: διατηρείται το προηγούμενο site.

## Δεδομένα

- Ελλάδα: https://epgshare01.online/epgshare01/epg_ripper_GR1.xml.gz
- Κύπρος: https://epgshare01.online/epgshare01/epg_ripper_CY1.xml.gz

Αυτά είναι εξωτερικά feeds τρίτου μέρους και μπορεί να αποκλείουν cloud υπολογιστές/VPN. Δοκίμασε την πρώτη εκτέλεση: αν αποτύχει, θα χρειαστεί εναλλακτικός διακομιστής ή άλλη επιτρεπόμενη πηγή. Εξασφάλισε ότι η χρήση/αναδημοσίευση δεδομένων επιτρέπεται. Δεν παρέχεται περιεχόμενο streaming, μόνο metadata προγράμματος.

## Λειτουργία

- `update.py`: λήψη, gzip/XML επαλήθευση και έλεγχος ότι υπάρχουν δεδομένα για σήμερα/αύριο, σύγκριση hash SHA-256.
- `build_epg.py`: δημιουργεί `site/index.html` με ενσωματωμένο πρόγραμμα.
- `.github/workflows/update-epg.yml`: χρονοδιάγραμμα και αυτόματη δημοσίευση.
- `site/status.json`: χρόνος τελευταίας επιτυχούς ενημέρωσης.

Οι καταχωρίσεις XMLTV έχουν ώρα έναρξης/λήξης. Η ομαδοποίηση παρόχων βασίζεται σε ονόματα καναλιών και δεν αποτελεί πιστοποιημένο κατάλογο συνδρομητικών πακέτων. Δεν γίνεται αυτόματη εξομοίωση διαφορετικών feeds. Για τα όρια της θερινής ώρας χρειάζεται περαιτέρω ειδικός έλεγχος εμφάνισης.

## Τοπική εκτέλεση

Με Python 3.10+ και σύνδεση στο διαδίκτυο:

```bash
python update.py
python -m http.server 8000 --directory site
```

Άνοιξε http://localhost:8000/ στο browser.
